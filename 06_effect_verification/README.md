# 06 効果検証｜レビュー（検証する側）

CVR改善の2レイヤーそれぞれで、05が出した **分析の妥当性** と **施策** を独立にレビューする「検証する側」。
作る人（05）と検証する人（06）を分けることで、自分の分析を自分で正当化するのを防ぐ。

**旧構成では②「個別施策（対象ページ選定）」と③「ABテスト（改善案）」のレビューが別段だったが、
05側の統合（`05_campaign_optimization/README.md` 参照）にあわせて1段に統合した。** ②の
`creation_review` は選定と改善案を別々に判定し、両方が妥当なときだけ確定版へ反映する
（詳細は `2_target_page_plan/creation_review/prompts/review.md`）。

## 2レイヤー × レビュー

| レイヤー | analysis_review（分析の妥当性） | creation_review（施策のレビュー） |
|---|---|---|
| **① 全体施策** `1_overall_strategy/` | 05分析の数値・手法を検算 | 全体方針をコンテキスト視点で是正 |
| **② 施策** `2_target_page_plan/` | ページ分析の検算 | 対象ページ選定と改善案を**別々に**是正・判定 |

## レビューの分業
- **数値が正しいか**（検算・データソース・統計手法）→ `analysis_review`
- **方針/施策がコンテキスト的に正しいか**（ターゲット/競合/方針）→ `creation_review`

## データソース
GA4 API（ABテストツール併用）。**BigQuery連携は将来対応**。
