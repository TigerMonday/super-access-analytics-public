# 全体施策｜施策作成レビューエージェント

> 全体方針をコンテキスト視点でレビューする（数値の検算ではない）。

| 項目 | 内容 |
|---|---|
| レイヤー | ① 全体施策 |
| データソース | —（方針テキスト＋01コンテキスト） |
| ステータス | プロトタイプ実装済み（prompts/review.md） |

## 役割
ターゲット・競合・プロジェクト方針と照らして「この方針で本当に良いか」をフィードバック。例:『このターゲットなのにここを最優先で良い?』。外部視点でバイアスを排除する役割。

## 入力
creation の全体方針案 / 01コンテキスト（profile・constraints・stakeholders）

## 出力（スコープ）
方針へのレビューコメント（妥当性・抜け漏れ・優先順位の指摘）

## 連携
creation と対話的に往復
