# ② 施策｜施策作成レビューエージェント（対象ページ選定＋改善案）

> 対象ページ選定と、そのページの改善案を、それぞれ独立にコンテキスト視点でレビューする。

| 項目 | 内容 |
|---|---|
| レイヤー | ② 施策（対象ページ選定＋改善案） |
| データソース | — |
| ステータス | プロトタイプ実装済み（prompts/review.md） |

## 役割
選んだ対象ページが、ターゲット・CV直結度の観点で妥当か（例: CVRが最も低いのが認知獲得用LPでも、着手すべきはCV直結LPでは? という是正）と、その改善案が仮説・計測できる設計・ターゲットと整合しているかを、**別々の判定として**レビューする。

**旧・対象ページ選定レビューと旧・ABテスト施策レビューを統合したもの。** 案の出来で選定の評価が引きずられる（またはその逆）のを防ぐため、`creation/prompts/create-page-plan.md` が出力を「## 対象ページ選定」「## 改善案（ページごと）」の2セクションに分けて書き、このレビューはその2セクションをそれぞれ独立に判定する（詳細は `prompts/review.md`）。

## 入力
- creation の出力（対象ページ選定＋改善案。`07-target-page-plan.md`）
- page_profile / 01コンテキスト（ターゲット・トーン・NG表現）
- `05-page-analysis.md`（選定根拠の転記検算に使う）
- 計測環境（measurement.yaml。改善案の計測設計チェックに使う）

## 出力（スコープ）
選定へのレビューコメント＋判定、改善案へのレビューコメント＋判定を別々に出し、両方妥当なら確定版へ反映する。

## 連携
creation と往復（差し戻すときは「選定のみ」「改善案のみ」「両方」を明示する）
