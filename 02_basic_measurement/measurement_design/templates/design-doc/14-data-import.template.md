## インポート手段

| 手段 | 適合シーン | 備考 |
|------|----------|------|
| GA4 管理画面で手動 CSV アップロード | 単発・少量 | スプレッドシート連携も可 |
| SFTP / 自動アップロード | 定期更新 | サービスアカウント鍵管理に注意 |
| BigQuery 経由 | 大量データ・複雑な前処理 | エクスポートとの組み合わせ |

## 取り込みフロー

1. GA4 管理画面 > データインポート で対応するデータソースタイプを選択
2. 上記表の「アナリティクスのフィールド」と「インポートするフィールド」のマッピングを設定
3. CSV / SFTP / BigQuery のいずれかでデータを供給
4. 取り込みステータスを定期確認 (失敗時はアラート)

## 注記

- 個人情報を含むフィールドはインポートしない (例: メールアドレス・電話番号は不可)
- `user_id` を使う場合はハッシュ化済み ID であること
- レポートタイム (Reporting Time) インポートは過去レポートには遡及しない
