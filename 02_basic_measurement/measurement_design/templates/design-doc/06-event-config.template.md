## 列の意味

| 列 | 説明 |
|----|------|
| event_name | GA4 に送る半角英数字小文字+アンダースコアのイベント名 |
| イベントの意味 | 人が読む説明 (日本語) |
| 実装方式 | GTM 実装 / GA4 自動収集 / 拡張計測 / コード直接 |
| 推奨イベント | GA4 の推奨イベント (Recommended Events) ならば `1` |
| キーイベント設定 | GA4 でキーイベント (旧コンバージョン) として登録するなら `1` |
| コンバージョンカウント方式 | イベントごと / セッションごと |
| 条件 (種別 / 演算子 / 値) | GTM のトリガー条件 |
| 主要なイベントパラメータ | このイベントで送信するパラメータ。カスタムは別途章 07 で定義 |

## 注記

- 自動収集イベント (`page_view`, `scroll`, `click`, `file_download` 等) は本表に含めても良いが「実装方式 = GA4 自動収集」とする。
- 命名規則: `docs/standards/naming-conventions.md`。
- 予約語: `docs/standards/reserved-words.md`。本表に予約語を独自定義として書かない。
