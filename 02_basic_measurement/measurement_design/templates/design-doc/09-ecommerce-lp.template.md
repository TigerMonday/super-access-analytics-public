## 本体との差分サマリー

| 観点 | 本体 (章 08) | LP / チャットボット |
|------|-------------|---------------------|
| 商品情報 (`items`) | フル取得 | 取れない場合あり (item 情報なしモード) |
| `view_item` のタイミング | 商品詳細表示時 | LP 表示時 / チャットボット起動時 |
| `add_to_cart` のタイミング | カート投入ボタンクリック | フォーム到達 / チャットボット起動 |
| `purchase` のタイミング | サンクスページ表示 | LP 内完了画面 / チャットボット完了 |
| URL パターン | `/products/*`, `/cart`, `/checkout` 等 | `/lp/*`, `/lp?u=広告URL名`, `/chat/*` 等 |

## URL ↔ イベント マッピング

| URL パターン | 主要イベント | 備考 |
|-------------|-------------|------|
| `/lp/{{campaign}}` | `view_item`, `add_to_cart`, `purchase` | 広告由来トラフィックの着地点 |
| `/lp?u={{ad_url_name}}` | 同上 | 広告 URL 名で計測 |
| `/chat/{{path}}` | チャットボット起動・完了系 | ステップ単位で `chat_step` パラメータ追加可 |

## チャットボット固有パラメータ

| `chat_branch` | STRING | 分岐先 ID | {{...}} |
| `chat_session_id` | STRING | チャットセッション一意 ID | {{...}} |

## 注記

- LP では `view_item` と `view_lp` の併存に注意 (どちらをコンバージョン経路に組み込むかを明示)
- アイテム情報なしの `purchase` を許容する場合、`value` `currency` `transaction_id` の 3 つは必須として担保
- LP の `affiliation` は `LP` (チャットボットは `LP_chat` など) と固定し、本体と区別できるようにする
