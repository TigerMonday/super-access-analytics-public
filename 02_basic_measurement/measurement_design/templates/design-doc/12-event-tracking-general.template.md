## 計測対象カテゴリの例

| カテゴリ | 該当する event_name |
|----------|---------------------|
| スクロール | `scroll`, `scroll_depth` |
| 動画 | `video_start`, `video_progress`, `video_complete` |
| ファイル | `file_download` |
| フォーム | `form_start`, `form_submit`, `form_error` |
| モーダル | `popup_view`, `popup_close`, `popup_action` |
| エラー | `js_error`, `404_view`, `api_error` |
| 検索 | `view_search_results`, `search_filter_change` |

## data 属性の使い分け

- リンク要素 (`<a>`, `<button>`): `data-gtm-link="..."` (章 11 と同形式)
- 非リンク要素 (`<div>`, `<form>` 等): `data-gtm-event="<event_category>,<event_name>,<event_label>"`
- 自動トリガー (スクロール深度・動画進捗) は data 属性不要、GTM 側の組込トリガーで取得

## バリデーション

- [ ] event_label が同一 category 内で重複なし
- [ ] 自動収集イベントと独自イベントで、同じ操作・同じ到達率を重複送信していない（標準 `scroll` と25/50/75/99%等の深度計測の併用は可）
- [ ] フォーム計測の場合、`form_start` と `form_submit` のペアが揃っている
