## 列の意味

| 列 | 説明 | 必須 |
|----|------|------|
| ID | 管理表内で一意の通し番号 | ✓ |
| ページ名・共通パーツ | 設置先の画面または共通パーツ名 | ✓ |
| event_name | GA4 に送るイベント名 (CTA は `click_cta` 固定が基本) | ✓ |
| リンクか否か | `<a>` / `<button>` の判別 (1 = リンク要素) | ✓ |
| 実装箇所 | 設置位置を表す案件固有のラベル | ✓ |
| デバイス別の設置個所 | SP・PC・共通 のいずれか | ✓ |
| event_category | GA イベントの category (`サンプル株式会社` 等のセクション名) | ✓ | <!-- leak-ok: ダミー会社名の統一表記（実在の社名ではない） -->
| event_label | category と組み合わせて遷移元を表す文字列 | ✓ |
| 文字数チェック | event_label の文字数 (GA4 の値長制限警告用) | ✓ |
| 追加 data 属性 | data-gtm-* 以外で必要な data 属性があれば記載 | 任意 |
| 計測タグ | HTML に貼る `data-gtm-link="..."` 等の例 | ✓ |
| 計測確認 (STG) | ステージング検証ステータス | ✓ |

## data-gtm-link 規約

```
data-gtm-link="<event_category>,<event_name>,<event_label>"
```

- カンマ区切り 3 値
- 値内のカンマ・改行は禁止 (代替記号: 全角カンマや `>` で区切る)
- 例: `data-gtm-link="サンプル株式会社,click_cta,サンプル株式会社>CTA_SegmentA_記事上"` <!-- leak-ok: ダミー会社名の統一表記（実在の社名ではない） -->

GTM 側で「カスタム HTML / DOM Element / 自動イベントリスナー」で `data-gtm-link` を読み、3 値に分割して `event_category` / `event_name` / `event_label` に送信する。

## バリデーション

- [ ] event_label が一意 (同一 category 内で重複なし)
- [ ] 文字数チェック列がフォームの値計算と一致
- [ ] data-gtm-link 値にカンマ・改行が含まれていない
- [ ] STG 検証が NG の行は本番反映前に修正
