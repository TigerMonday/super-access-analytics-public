## 接続方向の凡例

| 値 | 意味 |
|----|------|
| In | 外部 → GA4 (データを取り込み) |
| Out | GA4 → 外部 (データを送出) |
| In-Out | 双方向 |

## 連携時の確認項目

| 観点 | 内容 |
|------|------|
| 権限 | 連携先で必要なロール (オーナー / 管理者) を持っているか |
| 同意 | プライバシーポリシー / 利用規約への記載が必要か |
| データ範囲 | フィルタしたデータを送るのか、生データを送るのか |
| 保持期間 | 連携先での保持期間 (GA4 とは別管理になる) |

## 注記

- BigQuery 連携を有効にしている場合、エクスポートの形式 (日次 / ストリーミング)・保存期間を併記
- 終了 (deprecated) されたツール (例: Universal Analytics) は対象外。連携を残している場合は速やかに切る
