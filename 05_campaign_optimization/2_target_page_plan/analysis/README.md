# ② 施策｜分析エージェント

> 対象候補ページを分析し、どのページが優先かの根拠を出す。

| 項目 | 内容 |
|---|---|
| レイヤー | ② 施策（対象ページ選定＋改善案） |
| データソース | GA4 API（クライアント非依存で統一。BigQuery は V2 送り） |
| ステータス | プロトタイプ実装済み（prompts/analyze.md） |

## 役割
候補ページ群の規模・CV・導線イベント・流入を分析し、page_profile と合わせて優先ページの根拠を作る。エンゲージ率は選定に使わず、離脱は定義済み指標が無ければ計測不能とする。

## 入力
候補ページ群 / GA4データ / page_profile / 01コンテキスト

## 出力（スコープ）
ページ別の優先度根拠（数値分析）

## 連携
→ analysis_review / 05/2_target_page_plan/creation（対象ページ選定＋改善案）の入力
