## 改善案（ページごと）

### /seminar/20260410_ai-readiness-check（選定した「/seminar/ai-readiness-check」の開催回別URL）

**ページ状態（HTMLを見た結果）**
- FV見出し: 「AI活用の前に、まず社内データの状態を診断する」/ サブ: 「点在するデータを一つに集約し、精度を底上げする」
- ⚠️ **このURLは「開催済み」でCTAが「メルマガ登録」＝申込終了**。
  → X有料が終了済みLPに着地していたなら、反応の低さの主因はコピーでなく**運用（広告の出稿先）**。
  → 改善案は**開催中の同型セミナーLP**への適用を前提とする。運用面は別途報告（計測・運用フィードバック）。

**モバイルFV（Playwright・iPhone 14 Pro で実測）**
- `ctaInFold: false` … **モバイルFVに申込CTAボタンが無い**（H1はy=238、ボタンは画面外）
- `foldsToScroll: 9.8` … ページは約9.8画面分。FVで行動導線が見えない

**改善候補箇所（HTML＋モバイルFVを見て・根拠付き）**
| 箇所 | 弱そうな点 | 優先 |
|---|---|---|
| モバイルFVのCTA | FVに申込ボタンが無く、何をすればよいか分からない（`ctaInFold: false`） | 最有力 |
| FV見出し | 「診断する」が抽象的で、参加メリット/自分ごと感が即伝わらない | 高 |
| CTA文言 | 「メルマガ登録」で申込導線が弱い（開催中なら申込CTAが主であるべき） | 高 |

**仮説**: X広告経由の層（AIは導入したが自社データの活用に踏み出せていない）にとって、FV見出し「診断する」は具体像が浮かばず、参加後に何が得られるかが伝わらないまま離脱していると考えられる。**広告の課題提起とFV見出しの整合**を高める。

**変更要素**（候補から1つ）: モバイルFVを1セットとして扱う。FV内に申込CTAを配置し、見出し訴求を広告と一致させる。

**パターン案**（方向性＋具体案。最終文言は人が調整）
| パターン | 見出しの方向性 | FV内CTA |
|---|---|---|
| A | オリジナル（現状・FVにCTAなし） | なし |
| B | 課題直撃（広告一致）「データはあるのに活用できていない」を解く | FV内に「無料で申込」ボタン |
| C | ベネフィット具体「自社データ、AIに使える状態か？今すぐ無料診断」 | FV内に「無料で申込」ボタン |

**テスト設計**
- 成果指標: `complete_seminar`（主）＋ `form_start`（補助）
- パターン識別: イベントパラメータ `test_pattern` = A / B / C
- 対象: X有料流入 × モバイル ／ 開催中のセミナーLPで実施
