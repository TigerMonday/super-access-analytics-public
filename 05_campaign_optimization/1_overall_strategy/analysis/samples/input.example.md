# 入力例: 全体施策エージェント

```
CVR改善でどこから手をつけるべきか、全体方針を出してほしい。

- クライアント名: 自社サイト（sample-client）
- client_id: sample-client
- GA4 プロパティID: <GA4_PROPERTY_ID>（自社値は 01 コンテキストストア参照）
- 対象期間: 直近90日
- KGI/KPI: 問い合わせ・セミナー申込（キーイベント）
- toC/toB: toB中心
- HTMLレポート: 不要
```

※ client_id が 01 コンテキストストアに登録済みなら、GA4プロパティID・キーイベント・toC/toB区分・gotchas は自動補完され、聞かれない。
