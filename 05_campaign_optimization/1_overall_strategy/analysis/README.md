# 全体施策｜分析エージェント

> GAデータからサイト全体のボトルネックを分析し、改善方針の根拠を出す。

| 項目 | 内容 |
|---|---|
| レイヤー | ① 全体施策 |
| データソース | GA4 API（クライアント非依存で統一。BigQuery は V2 送り） |
| ステータス | プロトタイプ実装済み（prompts/analyze.md） |

## 役割
全体のファネル・流入チャネル別CVR等を分析し、どこにボトルネックがあるかを特定。06①施策作成の判断材料を作る。

## 入力
GA4データ / 01コンテキスト（KPI・key_events・gotchas）

## 出力（スコープ）
全体ボトルネック分析（チャネル別/導線別の弱点と根拠データ）

## 連携
→ analysis_review で検算 → 06/1_overall_strategy/creation の入力
