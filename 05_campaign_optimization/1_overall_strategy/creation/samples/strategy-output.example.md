# CVR改善 全体方針: 自社サイト（sample-client）

**対象**: sample-client / **期間**: 2026-03-18〜2026-06-16（90日） / **実施日**: 2026-06-16
**担当**: 全体施策エージェント / レビュアー: 人（承認者）

> ※ 架空のデータに基づくサンプル。チャネル構成・数値は例示のために作成したもの。実案件のデータではない。

## サマリ
- 同一LPへの有料流入は、自然検索と比べてCTA到達・CVが弱く、広告訴求と着地内容の不一致が疑われる。**広告とLPの整合確認を最優先**で着手すべき。
- Email/Direct/Organic Social はCV効率が高く、現状維持でよい。
- 次点は問い合わせフォームの完了率確認（EFO）。コンテンツSEOからの動向は検討事項が多くV2。

## Phase 2: 分析レビュー（検算）
- **CVR分母**: toB中心のため、Paid流入のCVRは「広告LP着地セッション」を `landingPagePlusQueryString` で絞って再計算すべき（全体分母では希釈）。
- **計測**: キーイベントの過剰発火・`gtm.*` 混入は確認済みで、CVは事業成果として扱える範囲。
- **ドメイン**: `hostName` 単一、予約ドメイン混入なし。
- 結論: 「LPO最優先」は数値上も支持。engagement 0.19 は計測ではなく実態の可能性が高い。

## Phase 3: 全体方針（着手先＋優先順位）
1. **LPO（有料流入LP）** … インパクト大・要件明確。**最優先**。広告メッセージとLPの不一致を疑う
2. **EFO（問い合わせフォーム）** … フォーム到達後の離脱を確認した上で次点
3. **コンテンツ改善（Organic流入）** … 中長期。V2扱い

## Phase 4: 方針レビュー反映
- toBターゲットで有料流入の質（リード適性）も論点。単なるCVRだけでなく「商談化するリードか」を②個別施策で確認する前提を追記。
- 競合/事業フェーズ的にもLPO最優先で齟齬なし。

## 適用した前提
- 期間: 90日 / attribution: ラストタッチ / CVR分母: 暫定で全体（②でLP着地に絞り再計算）
- データソース: GA4 Data API のみ（BigQuery不使用）

## 次のレイヤーへの引き継ぎ（→ ② 個別施策）
- 有料流入が着地している **どのLPを対象にするか** を ② 個別施策＋page_profile で精査
- フォーム到達→完了のファネルを ② で取得し EFO の要否を判断
