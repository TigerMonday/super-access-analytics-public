# 入力例: アドホック分析エージェント

エージェント起動時に答える内容のサンプル。形式は自由記述で OK。

---

## 分析依頼の例

### 例1: デバイス別CVR差を知りたい
```
モバイルとPCで CVR の差があるかを知りたい。
特に問合せフォームのCVRに差があるか、要因を見たい。
```

### 例2: 特定キャンペーンの効果検証
```
5/13〜15 にやった X 広告セミナーキャンペーン
（campaign: 202605_spring_seminar）の
リアル効果を知りたい。配信前後で全体のCV数がどう変わったか、
どのチャネル経由のCVが増えたか。
```

### 例3: 流入経路ごとの質の差
```
新規ユーザーがどの導線で問合せに至っているか。
特に X 広告経由とオーガニック検索経由で、
CVまでのリードタイムやフォーム到達率に差があるか見たい。
```

### 例4: 急減原因の特定
```
最近 complete_seminar の発火が減っている気がする。
日次推移を見て、減少が始まったタイミングと、
その時期に何が変わったかを特定したい。
```

---

## 答える項目

| 項目 | 内容 | 例 |
|---|---|---|
| 分析依頼 | 自由記述 | 上記例参照 |
| クライアント名 | 出力ファイル名に使用（01 の client_id と揃える） | `sample_client` |
| GA4プロパティID | 数値のみ | `123456789` |
| 対象期間 | デフォルト28日 | `90日` / `2026-04-01 ～ 2026-05-31` |
| 比較期間 | 任意 | `前期比` / `前年同月比` / `なし` |

※ クライアント名・GA4プロパティID は Step 0 のコンテキストストアで補完できた場合は聞かれない。
