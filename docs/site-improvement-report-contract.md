# サイト改善レポートの施策契約

個別施策まで作るサイト改善レポートに適用する。全体方針だけの途中成果物へ架空の個別施策を足さない。

## 続行確認はチャットで行う

- 全体方針が確定した時点で、利用者にチャットで方針の要約・主な根拠または留意点・次に行うことを示し、「この方針で、対象ページの選定とページ別の改善案作成まで進めてよいですか？」と明示的に聞く。
- クライアント向けレポートには「個別ページ改善へ進む前の確認」等の確認待ちの章を作らない。進行確認は会話、レポートは判断材料と提案、という役割を分ける。
- 利用者が了承したら `page_profile` から再開し、対象ページ選定とページ別改善案の確定まで自動で続ける。同じ段の途中に追加の承認待ちは設けない。
- レポートの出力やパス案内だけでは続行確認を取ったことにならない。チャットで直接質問し、返答があるまで個別ページ改善へ進まない。

- 本文は改善方針から始める。「このレポートで分かること」「すぐ直す運用・計測」「Search Consoleの扱い」は作らない。接続・取得・検算の事情は内部記録に置く。判断に必要なデータ制約は該当する根拠に短く添える。
- クライアント向け本文は、結論1〜3文＋判断用の表を基本単位とする。結論、表の読み方、指標定義、実装順は表の前へまとめ、表の後には出典・脚注だけを置く。1章に複数の表がある場合は表ごとに小見出しを付け、「小見出し＋説明＋表」を同じ面に置く。長い説明段落を施策ごとに並べない。「根拠と改善箇所」は **判断 | 根拠 | 留意点** の表、「実施後の判断」は **確認結果 | 判断 | 次の対応** の表にまとめる。同じ内容を施策表・根拠文・実施判断で繰り返さない。
- 施策表は **対象ページ | 施策概要 | 施策詳細 | 改善指標** の4列。URL、変更位置、具体的な追加・変更・削除内容を示す。指標は分子・分母と最終成果へのつながりを示す。
- 独立した施策候補を5件以上検討する。同じCTAの文言違い、計測準備、未確認ページの欠点の創作で水増ししない。確実な根拠が足りないものは検証候補と明示し、実施推奨と分ける。5件の妥当な候補が成立しない場合は不足を利用者に伝え、無理に確定しない。
- 根拠は数値による課題、実ページで観察したUX上の課題、顧客理解に基づく検証仮説に分ける。既存要素の存在を確認してから不足と書く。
- フォーム改修は平均値との差やCVへの近さだけで採用しない。同定義での不振・具体的な操作障害・ユーザーテスト等の根拠を要する。5%を全業種共通の閾値にしない。
- ICEはI（成果への影響）・C（確信度）・E（実行容易性）を各1〜10、積I×C×Eで統一。高いほど優先。各点の理由を残す。Cは数値と観察の両方があると7〜8、観察中心5〜6、仮説中心3〜4を目安とし、効果実証と混同しない。Eは文言修正8〜9、既存部品追加6〜7、新規制作3〜5を目安に、体制未確認なら暫定とする。Iは成果との距離と対象規模を併記し、売上予測を創作しない。
- 順位表は施策名、I、C、E、ICE、採点理由。スコア順と実装依存関係を区別する。
- Search Consoleは検索語・対象ページ・検索意図を施策に結び付ける。オウンドメディアは新規記事、既存記事更新、関連サービスへの導線を候補とする。クエリ×ページの対応が不明なら特定クエリの流入先を推測しない。
- 配置変更が伝わりにくい上位施策に、変更位置と文案が分かる簡易ワイヤーを付ける。架空の改善率を載せない。参考事例は出典・業態・目的・変更点・評価方法・適用条件を記録し、自社への効果保証には使わない。
- 公開事例は `common/improvement_cases/README.md` の情報源から課題に応じて都度調査する。共通台帳への蓄積・全件収集は行わず、採用事例だけを案件の `05_cvr/_data/adopted-cases.md` に保存する。
- 外部事例・UX調査は同READMEの「根拠としての採用条件」を満たすか個別確認する。成果数値だけで対象数・期間・指標・比較方法が不明なものを、効果の根拠として掲載しない。根拠不足の事例でICEの確信度を上げない。
- 支援会社・ツール提供会社の事例集を改善案の情報源として使い、個別原典を確認する。本文では「実施された変更／自社への応用／適用条件」を出典付きで示す。自社の既存数値・UI観察より事例を優先せず、似た事例の存在だけでICEを引き上げない。
- 完成前に `python tools/validate_site_improvement_report.py <report.md>` と既存の文章・接続検査を行う。4列施策表、ICE表、根拠表、実施後判断表のいずれかが欠けた状態で配布しない。機械検査後も数値・採点・提案の妥当性をレビューする。
