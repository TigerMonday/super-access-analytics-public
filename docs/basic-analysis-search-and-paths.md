# 基本分析の検索推移・CV前経路

## Search Console

取得可能な場合、月次4指標を2段のグラフと実数表で示す。上段は表示回数（imp）とクリック数（click）、下段はCTRと平均掲載順位を左右の独立軸で重ねる。年月・単位・目盛り・段の境界を表示し、順位は小さいほど上になる反転軸とする。左右の軸が異なるため、線の交点や高さを値の一致と解釈しない。生成は `chart: search` を使い、表の列順は月・表示回数・クリック数・CTR・平均掲載順位とする。

CTRは月の総クリック÷総表示回数で計算し、日別CTRの単純平均にしない。平均順位はAPIの月次集計値、または表示回数加重で求める。部分月は明示し、完全月と同条件として比較しない。データ欠損はゼロにしない。掲載方針や接続状況の宣言を本文に書かない。

## BigQuery接続時の追加分析

標準の分析項目は次の2つだけとする。

1. **CVまでの主なページ遷移**：経路、CVセッション数、全対象CVセッションに占める構成比。
2. **ページ閲覧後のCV率**：ページURL、対象閲覧セッション数、その閲覧後にCVしたセッション数、両者の比率。因果的な貢献度と誤解される「CV寄与率」は見出しに使わない。

CV直前ページ、CV前の閲覧頻度、流入元・端末別経路は独立した標準項目にしない。再訪・セッション横断分析も、別途依頼された場合だけ検討する。

- CV定義ごとに、セッション内の最初のCVより前のページ閲覧を並べる。CV後のサンクスページ・回遊を含めない。ユーザー識別子とセッションIDの組を用い、ID欠損は結合しない。同時刻イベントで順序を確定できない場合は不確実性を残す。
- 上位経路は具体的なURLで表示し、CVセッション数・全対象CVセッションに占める割合を示す。切り詰めた経路を完全経路と呼ばない。ページ群で見たい場合は、確認済みの分類を `--page-groups-json` で指定する。
- ページ別の分母は、当該CV未発生の時点でそのページを閲覧したセッション数（非CVセッションを含む）。分子は、その閲覧後に当該CVが発生したセッション数。CV後だけの閲覧は分母・分子とも除外する。同一ページの反復閲覧はセッション内で1件とし、CV別に集計する。母数を必ず併記し、少数の100%を高貢献と断定しない。
- フォームは識別し、サンクスページを改善対象の検討ページに混ぜない。記事・事例・サービスの役割を読む。
- ページ閲覧後のCV率は関連を示す指標であり、そのページがCVを増やした因果効果ではない。流入元・入口・端末等の構成によっても変わる。
- セッションをまたぐ経路は別分析。識別方法・遡及期間を決め、同意や識別子欠損により追えない利用者を明示する。同一端末の結果をクロスデバイス全体としない。
- 取得前にスキャン量を見積もり、実行時にも課金上限を設定する。全期間・全イベントの無制限走査をしない。BQ未接続時に経路を推測して掲載しない。

`bq_cv_paths.py` は `bq_cv_analysis.py` を利用し、CV別の初回CV前経路とページ閲覧後CV率を集計する。標準は具体的なURLで、分類を指定した場合だけページ群で表示する。SQL組み立て・表示・課金上限のローカルテストを実施済み。BigQuery上での実行と実データとの照合は未実施のため、初回接続時に確認してからレポートへ採用する。
