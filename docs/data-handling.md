# データの扱いについて

このツールが、あなたのGA4データをどこに送り、どこに置くのかをまとめる。社内で利用の説明をする際にそのまま使える内容にしている。

## 短くまとめると

- このツールは、あなたのパソコン（またはあなたが用意したサーバー）の中だけで動く。分析専用の外部サーバーやクラウドサービスは持たない。
- GA4から取得したデータは、実行したパソコンの中にファイルとして保存される。取得後にどこかへ自動送信することはない。
- 分析やレポート文の生成にAIエージェントを使う場合、取得したGA4/GTMデータの一部が、そのAI製品の提供会社へ送られる。送信先はClaude CodeならAnthropic、CodexならOpenAI、GeminiならGoogleなど、利用する製品によって変わる。
- Python CLIの既定は外部LLMバックエンドを呼ばない。別のAI CLI・APIへ自動転送することはない。

## データの流れ

1. **取得**: サービスアカウントの鍵（`docs/setup-ga4.md`で準備したもの）を使い、GoogleのGA4 APIから実行したパソコン宛にデータを取得する。通信相手はGoogle（`analyticsdata.googleapis.com` 等）だけで、この段階では他社に送られない。
2. **保存**: 取得したデータは、実行したパソコンの中の、リポジトリ直下 `outputs/{識別子}/` にファイル（JSON・Markdownなど）として保存される（実行したフォルダの位置に関わらずリポジトリ直下に集まる）。このフォルダはGit管理の対象から意図的に外してあり（`.gitignore`）、GitHubなどのリモートリポジトリには上がらない。
3. **分析・レポート生成**: 保存したデータ（または取得直後のデータ）を、現在利用しているAIエージェントが読み、示唆・文章を生成する。このとき数値・ページパス・流入経路・イベント名・GTM設定などが、そのAI製品の提供会社へ送られる場合がある。GA4のレポート系APIは集計データを扱うため、通常の使い方ではユーザーIDやメールアドレスを取得対象にしない。
4. **成果物**: 生成されたレポート・設計書は、2と同じく `outputs/{識別子}/` 配下にファイルとして保存される。人に共有したい場合は、そのファイルを自分で送る・アップロードするといった操作が必要で、ツールが自動で外部に公開することはない。

Google DocsまたはGoogle Sheetsへの出力先を利用者が設定した場合は例外で、レポート生成後に指定済みのGoogleファイルへ書き込む。書き込み先を指定していない状態でGoogleへ成果物を送ることはない。書き込みにはGA4閲覧用とは別のGoogle出力専用サービスアカウントを使い、対象ファイルだけをそのアカウントへ編集者として共有する。

## AI提供会社への問い合わせについて

AIエージェントがローカルファイルを読むと、その内容が提供会社のサーバーへ送られる場合がある。契約、保持期間、学習利用、管理者設定は利用製品ごとに異なる。

- Claude Codeを使う場合はAnthropic、Codexを使う場合はOpenAI、Geminiを使う場合はGoogleの契約・利用規約を確認する。
- Cursor、Windsurf、Clineなどで外部モデルを選択する場合は、そのツール提供会社に加え、選択したモデル提供会社への送信条件も確認する。
- Pythonから任意の `claude_cli` / `anthropic_api` バックエンドを使う場合は、通常のエージェント利用とは別の外部送信になる。送信先と送信データを説明し、クライアントごと・送信先ごとに初回だけ明示承認を得る。初回実行では `--approve-external-ai` を付け、承認記録を01の `profile.yaml` に保存する。以後は同じ送信先について聞き直さない。
- AIなしで機械診断まで行う場合は `--llm-backend none`（既定）を使う。この場合、分析文の生成を目的としたAI提供会社への送信は発生しない。

## それ以外に外部へ送信するもの

- GA4以外に、GTM（Google Tag Manager）の設定を読み取る機能があるが、取得段階の通信先はGoogleで、取得後の扱いはGA4データと同じ（2・3のとおり）。
- 外部リサーチ機能（競合・市場調査）では、公開Webサイトの閲覧・検索を行う。GA4データはこの通信には含まれない。
- このツールには、利用状況を開発元へ送信するような計測・テレメトリの仕組みは無い。
- 利用者が明示したAIエージェント・任意バックエンド以外の分析SaaSやログ収集サービスへ自動送信する処理は無い。

## 補足: 鍵ファイルについて

GA4への接続に使うサービスアカウント鍵（JSONファイル）は、実行したパソコンのローカルに置いたものをそのまま使う。この鍵ファイル自体をどこかにアップロードしたり、AIへの問い合わせに含めたりしてはいけない。置き場所と取り扱いの注意は `docs/setup-ga4.md` を参照。
