# 市場・顧客理解レポートの固定構成

作成前に `service-understanding.md` を実行する。対象サイトの確認、サービス全体の把握、自社・競合のサービス一覧保存を先に行い、公開情報で分からないことだけ利用者へ相談する。

分析項目と順序の正本は `market-report-template.md` のH2とする。最初の8章が固定分析項目、最後の「調査方法と限界」は根拠説明である。案件によって削除・統合・改名・並べ替えない。「自社が選ばれる理由」を「勝ち筋」「3Cの交点」に変更しない。

作成前に8項目の対象・既存根拠・不足情報を整理する。対象や比較軸を左右する不明点は利用者に相談する。案件固有の論点は該当章のH3以下に追加し、固定章を置き換えない。顧客像や競合の数、結論は案件ごとに変えてよい。

事前相談はテーマフォルダの `data/research-intake.json` に保存する。競合候補、調査目的・期間・情報源条件、既存資料、顧客の声、選ばれる理由、選ばれなかった理由、提供限界のいずれかが未確認のままなら、候補探索は継続してよいが最終版として配布しない。`tools/validate_market_report.py` はこの記録も検査する。

表紙情報の直後には、`market-report-template.md` の `<!-- pictograms: insight,analysis,target -->` 付き3列表を置き、顧客・市場の要点／競合・代替との違い／次の判断を各1〜2文でまとめる。これは定性要約であり、根拠のないスコアや疑似的な数値グラフへ置き換えない。HTML/PDFでは `report_export` がピクトグラム要約へ変換する。

固定8章は長文だけで構成しない。「市場」「顧客」「競合・代替手段」「自社」「自社が選ばれる理由」「顧客像の整理」「カスタマージャーニー」「分析から導く示唆」には、それぞれ比較表またはジャーニー表を最低1つ置く。本文は表から読み取る結論を原則1〜3文に絞り、同じ内容を人物別の説明文と表で重複させない。

「顧客像の整理」は顧客像を同じ比較軸で並べる1表を正とする。「カスタマージャーニー」は顧客像ごとに、5段階を列、状況・行動／認識／障壁／次へ進むきっかけを行にした1表を正とする。ペルソナの人物紹介をカスタマージャーニー内へ再掲しない。各セルは原則1文・40字程度までとし、長い根拠や検討過程は `data/` の根拠台帳へ置く。

「顧客」章は事例紹介だけで終えず、サービス別に顧客の状況・課題・求める支援・選定基準を具体化する。事例がない場合もサービスから仮説を作り、`docs/report-consultation-quality.md` の「顧客理解は、よくある相談・要望から聞く」に従って実情を確認する。事例・ヒアリング・サービス由来の推定を区別する。「顧客像の整理」章では、これらを検討行動の違いでまとめる。サービス数に合わせて架空の人物を増やさない。

情報が不足しても章を削除しない。「未確認」と理由・必要な確認を残す。適用外なら理由を記載する。各章は手順の宣言ではなく、具体的な分析結果と根拠を書く。テンプレートの説明文は執筆指示であり、完成本文に残さない。出典は該当記述の近くに置く。

内部の根拠分類や制作事情を利用者向け本文・見出しへ出さない。`会社側仮説`、`利用者未確認`、内部ID・英字の根拠分類は非公開資料だけで使う。根拠の弱さが判断に必要な場合は、表の直後に `<small>※ ...</small>` で簡潔に置くか、「調査方法と限界」へ集約する。分析段落は市場・顧客・競合・自社について分かった事業上の意味を先に述べる。

「市場」章は対象サービスの需要・顧客課題、供給形態、代替手段、変化要因を根拠から説明する。自社の問い合わせ増減や会話で出た原因仮説への返答を、市場の状況として置かない。市場の増減は同じ定義・期間の比較根拠がある場合だけ述べる。統計が不足する場合も「分からない」の説明を主題にせず、確認できた市場構造と具体的な需要を先に示し、限界を短く添える。個社事例は需要の存在例であり、市場全体の傾向・規模の証拠にはしない。技術の登場だけで既存サービスの需要減少を推定しない。自社への提案は「分析から導く示唆」へ分ける。

完成後・HTML/PDF変換前に、リポジトリルートで以下を実行する。失敗した成果物は完成扱い・配布しない。

```sh
python tools/validate_market_report.py outputs/CLIENT/03_research/customer_understanding/00_3c_persona_journey_report.md
```

検査は章の欠落・重複・順序違い・説明文の残存・空章・要点ピクトグラム指定・主要章の表・ジャーニー表の欠落を検出する。分析の妥当性は保証しない。別途、出典との対応、事実と推定の区別、顧客像とジャーニーの対応、示唆の根拠を人または実行エージェントが確認する。
